# Your Nomo page

A personal page made from one markdown file. This repo is the starting point.

1. Click **Use this template**, name the new repo `.nomo`, and keep it public.
2. Edit `human.md`. Swap the name, the links and `assets/me.jpg` for yours.
3. Open `nomo.md/yourusername`. Changes show up about a minute after you push.

Or tell your agent:

```
Make my Nomo page at nomo.md/yourusername. Draft it from my GitHub profile and show me before you push. Follow https://nomo.md/AGENTS.md
```

The syntax is at [nomo.md/docs](https://nomo.md/docs).
